# brand

Brand facts for HooCode, shared by the recording, the trailer and the teaser.

- `wordmark.txt`: the 3-row glyph (7 columns), as the TUI draws it (`crates/hoocode-code-tui-app/src/wordmark.rs`). Each column is coloured from the accent to violet gradient.
- `brand.json`: colours, name, version, tagline and install lines. The trailer's colours and text come from here.
- `README.md`: this file.
